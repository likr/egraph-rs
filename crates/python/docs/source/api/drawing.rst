Drawing Module
==============

This module provides zero-copy SoA coordinate buffers (``Layout2d``, ``Layout3d``, ``LayoutNd``, ``ManifoldLayout2d``), edge polyline storage (``EdgePolylines``), and spatial indexing trees (``ArenaOctree3d``, ``DynamicKdTree``).
