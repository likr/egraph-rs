YifanHuSolver
=============

Cooperative multilevel Yifan Hu force-directed solver using Edge Contraction + Maximal Independent Vertex Set (``EC+MIVS``) coarsening and ``backend="barnes_hut" | "exact"`` across ``target="layout2d" | "layout3d" | "layout_nd"``.
