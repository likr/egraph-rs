SgdSolver
=========

Cooperative ``u32`` SoA Stochastic Gradient Descent solver supporting Track B 3-tier Sparse Barrier SGD (``sparse_barrier_dog``, ``sparse_barrier_from_landmarks``), ``snap_t_fdp``, ``pacmap_graph``, ``sgd2``, ``full``, ``random_pair``, ``omega``, ``streaming_negatives``, custom pairs, and non-Euclidean ``ManifoldLayout2d`` optimization.
