FruchtermanReingoldSolver
=========================

Cooperative Fruchterman-Reingold force-directed layout solver supporting ``"exact"``, ``"barnes_hut"``, and ``"grid"`` repulsion backends across ``target="layout2d" | "layout3d" | "layout_nd" | "manifold2d"`` (``"exact"`` only for ``"layout_nd"`` and ``"manifold2d"``).
