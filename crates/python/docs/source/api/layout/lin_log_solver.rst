LinLogSolver
============

Noack (2007/2009) LinLog energy-model force-directed layout solver (``LinLogSolver``) supporting ``"edge_repulsion"`` and ``"node_repulsion"`` with ``backend="barnes_hut" | "exact"`` across ``target="layout2d" | "layout3d" | "layout_nd"`` (``"exact"`` only on ``"layout_nd"``).
