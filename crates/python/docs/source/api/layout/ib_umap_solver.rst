IbUmapSolver
============

Cooperative Interpolation-Based UMAP (``ibUMAP``) solver for ``Layout2d`` (``target="layout2d"``) with ``"ib_fft"`` / ``"barnes_hut"`` / ``"exact"`` repulsion, precomputed landmark construction (``from_landmarks``), and degree-aware hub damping.
