TsNetSolver
===========

Unified Track A tsNET solver supporting Pure 1+2-Hop adaptive perplexity (``pure_2hop``), direct row-normalized ``A1 + w2 * A2`` affinity (``from_graph_row_normalized``), custom $k$-NN (``from_knn``), sparse probabilities (``from_probabilities``), and partial-BFS initialization across ``"fft"``, ``"linear_fft"``, ``"barnes_hut"``, and ``"exact"`` backends.
