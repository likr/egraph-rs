ForceAtlas2Solver
=================

Cooperative ForceAtlas2 continuous force-directed placement solver with optional Barnes-Hut acceleration and ForceAtlas2 logarithmic attraction mode (``linlog_mode``, Jacomy et al. 2014, distinct from Noack 2007 true LinLog ``LinLogSolver``).
