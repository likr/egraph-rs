EdgePolylines
=============

Owned, UAF-safe edge polyline container storing ``edge_offsets`` and target-typed control points (``Layout2d``, ``Layout3d``, or ``LayoutNd``) for edge routing solvers such as :class:`egraph.FdebSolver`.
