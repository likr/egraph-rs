LayoutNd
========

Contiguous $N$-dimensional Structure-of-Arrays (SoA) coordinate buffer supporting ``float64`` (default) and ``float32``, exposing ``dims``, ``copy()``, ``get()``, ``set()``, ``normalize_std()``, and zero-copy ``coords(copy=False)``.
