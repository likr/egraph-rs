# Verification and Testing Guide for `egraph-rs`

This skill defines the tiered verification harness across Native Rust, Python (PyO3), and WebAssembly (`wasm-bindgen` / Node / Browser) in `egraph-rs`.

## 1. Tiered Verification Runner (`scripts/verify.sh`)

**Staged Verification Sequence**: Always verify Rust core changes first (`--fast --crate <name>`, then `--rust --invariants`) until the Rust API is stable; only then build and verify Python (`--python`) and WASM (`--wasm --build-wasm`) bindings, followed by `--parity` and `--docs`.

Always prefer `./scripts/verify.sh` over raw `cargo`/`maturin`/`unittest` invocations. It automatically sets:
- `RUST_FONTCONFIG_DLOPEN=1`
- Single-thread guards (`OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`, `MKL_NUM_THREADS=1`, `RAYON_NUM_THREADS=1`, `NUMEXPR_NUM_THREADS=1`)
- `RUSTC_WRAPPER=sccache` (shared compilation cache across git worktrees; if deep sandbox `TMPDIR` paths trigger Unix socket `SUN_LEN` errors during `cargo clippy`, bypass cleanly with `RUSTC_WRAPPER=env` without altering repository files)
- `CARGO_BUILD_JOBS` throttled by `EGRAPH_PARALLEL_WORKERS` (`1->8`, `2->5`, `3->4`, `>=4->2`)
- Isolated worktree-local `$REPO_ROOT/.venv` (`uv`-managed Python 3.12)
- `cargo nextest run` when installed

| Tier | Command | When to Run |
|---|---|---|
| **Tier 0 (`--fast`)** | `./scripts/verify.sh --fast [--crate <name>] [--json-summary <path>]` | After every local edit in a worktree (stays debug for quick crate loops; checks `rustfmt`, `clippy -D warnings` + `clippy.toml`, `nextest` on changed/`--crate` packages, `std::thread` scan). For binding crates: `--crate egraph-python` runs `clippy` and directs to `--python`; `--crate egraph-wasm` runs `wasm32` check + `clippy` and directs to `--wasm`. |
| **Tier 1 (`--rust`)** | `./scripts/verify.sh --rust [--debug-rust] [--strict]` | Before merging a Rust crate branch (full workspace `fmt --check`, `clippy`, and fast parallel `[profile.release]` `nextest --workspace` + batched feature-matrix passes via `run_batched_matrix`: `all_features` [13 crates `--all-features`], `no_default_layout` [9 layout/routing crates `--no-default-features`], `no_default_metrics` [2 metrics crates `--no-default-features`], `no_default_egraph` [`egraph --no-default-features`], `no_default_dataset` [`egraph-dataset --no-default-features`], `embedded_dataset` [`egraph-dataset --features embedded`], and `no_default_baselines` [6 crates `--no-default-features --features baselines`]; `--debug-rust` opts into debug tests; published PyPI wheels separately use `[profile.dist-release]` with `lto = "thin"` and `codegen-units = 1`). |
| **Tier 1 (`--python`)** | `./scripts/verify.sh --python [--test <module>] [--dev-py]` | After Rust core is verified and `crates/python` bindings are updated (rebuilds with `maturin develop --release` using fast `[profile.release]` into local `.venv`; `--dev-py` opts into debug builds and `--release` remains accepted; runs `unittest`, `mypy --strict` on `crates/python/python/egraph` and the 30 strictly typed domain test files `TYPED_PY_TEST_NAMES`, and `stubtest egraph` across all package modules: `__init__.py`, `interop.py`, `_core.pyi`, `_core_types.{py,pyi}`, and `_core_<domain>.{py,pyi}`). |
| **Tier 1 (`--wasm`)** | `./scripts/verify.sh --wasm [--test <name>] [--build-wasm]` | After Rust core is verified and `crates/wasm` bindings are updated (`wasm32` check + `wasm-pack test --node crates/wasm`; `--build-wasm` runs `(cd crates/wasm && wasm-pack build --target web --no-opt --profile wasm-release -d pkg .)` with explicit `codegen-units = 1` + `assemble_pkg.mjs` delegating to `crates/wasm/scripts/assemble/*.mjs` + explicit `wasm-opt -Oz --enable-bulk-memory --enable-nontrapping-float-to-int` + `node crates/wasm/tests/node_esm_smoke.mjs` delegating to `crates/wasm/tests/esm_smoke/*.mjs` + size report). |
| **Tier 2 (`--invariants`)** | `./scripts/verify.sh --invariants [--strict]` | Checks `cargo tree --edges normal -e features` (`rayon`/`linfa`/`wgpu`/`getrandom`-free across all 28 `egraph*` workspace crates and feature variants), `std::thread`/`thread_rng` scans, `wasm32` compile across all 26 wasm32-capable `egraph*` crates (excluding host-only `egraph-python` and `egraph-cli`), and cross-target packaging metadata via `scripts/verify_helpers.py` (`<= ~500L` helper CLI reading `[workspace].members`, `crates/python/pyproject.toml`, and `crates/wasm/package.json` `version` + npm provenance `repository`; `--mode strict` passes `--strict-metadata` across all 28 crates with `hard_fails=0`). |
| **Tier 2 (`--parity`)** | `./scripts/verify.sh --parity` | Runs `scripts/parity_harness.py` delegating to `scripts/parity/*.py` (30 modules covering deterministic fixtures, adversarial `NaN`/error checks, and optional Node.js WASM cross-checks). |
| **Tier 2 (`--docs`)** | `./scripts/verify.sh --docs` | Auto-provisions `crates/python/docs/requirements.txt` (`sphinx`, `sphinx-rtd-theme`, `matplotlib`) in `$REPO_ROOT/.venv` if missing, builds Sphinx HTML + `sphinx -b doctest` (into cleaned temp dirs), TypeDoc from `crates/wasm/typedoc.json`, and `npm --prefix examples/web run build`. |
| **Tier 3 (`--all`)** | `./scripts/verify.sh --all [--build-wasm] [--strict]` | Full integration sign-off / pre-PR gate (`--rust --python --wasm --invariants --parity`; combine with `--docs` and `node crates/wasm/tests/playwright_smoke.mjs` for full cross-target release gates). |

## 3. Mandatory Steps Before Completion

Whenever a task is ready to be completed:
1. Run `cargo fmt --all` and verify clean formatting (`cargo fmt --all -- --check`).
2. Run `./scripts/verify.sh --fast` (or `--rust` / `--python` / `--wasm` / `--all` / `--docs` matching scope; `--rust` and `--python` use fast parallel `[profile.release]` with `lto = false`, `--debug-rust` / `--dev-py` opt into debug builds, and `--fast` stays debug).
3. Verify `clippy.toml` (`std::thread` forbidden), `scripts/verify_helpers.py` + `scripts/packaging_checks.py` (`<= ~400L` packaging/package-list helpers), and `./scripts/check_invariants.sh --mode strict` produce zero violations (`hard_fails=0`); always pass `--edges normal` when inspecting dependencies manually with `cargo tree --edges normal -e features` so dev-dependencies do not trigger false positives, ensure `Cargo.lock` exists (`cargo generate-lockfile`), and never merge `cargo tree` stderr into stdout (`2>&1`) so lockfile-generation messages cannot trigger false positives. Run both the workspace-wide banned-dependency scan (`cargo tree --workspace --edges normal -e features | grep -E '(^|[^[:alnum:]_-])(rayon|linfa|linfa-nn|linfa-clustering|wgpu)([^[:alnum:]_-]|$)'` returning zero matches) and strict per-crate `getrandom` + feature-matrix checks across all 28 `egraph*` crates (`egraph-core`, `egraph-ffi`, `egraph-dataset`, `egraph-spatial-{trees,fft,crossings}`, `egraph-edge-routing`, `egraph-linalg` + `egraph-linalg-{mds,amg}`, `egraph-neighborhood`, `egraph-clustering`, `egraph-metrics-{geometry,cluster}` + `egraph-metrics`, `egraph-layout-{constraints,stress,force,neighbor,sgd,embedding,multilevel,refine,composite}`, `egraph-rs`, `egraph-cli`, `egraph-python`, and `egraph-wasm`).
4. **PyO3 `extension-module` unit-test rule**: Pure-Rust helpers tested under `#[cfg(test)]` inside `crates/python` MUST return plain Rust types (`Result<_, String>` or `Option<_>`), never `PyErr` / `PyValueError`, so `cargo test --workspace` and `cargo nextest run --workspace` link cleanly on macOS without `libpython` symbols.
5. For Python binding changes, verify inside the worktree's isolated `.venv` (never pollute `/Users/likr/graph-drawing-experiments/.venv` from an unmerged worktree), and confirm `.venv/bin/mypy --strict` across `crates/python/python/egraph` and all 30 strictly typed domain test files (`TYPED_PY_TEST_NAMES` in `scripts/verify.sh`), `.venv/bin/mypy --strict --ignore-missing-imports scripts/verify_helpers.py scripts/packaging_checks.py scripts/bootstrap_crates_io.py scripts/parity_harness.py scripts/parity/` (as enforced in CI), and `.venv/bin/stubtest egraph` across all package modules (`__init__.py`, `interop.py`, `_core.pyi`, `_core_types.{py,pyi}`, and `_core_<domain>.{py,pyi}`, with `scipy`, `networkx`, and `igraph` installed for `egraph.interop`) pass cleanly.
6. **WASM Domain-Named Test Registration & Browser Smoke**: Name all newly added Rust, Python, and WASM test files after their domain/feature (`tests/<domain>.rs`, `crates/python/tests/test_<domain>.py`, `crates/wasm/tests/<domain>.rs`)—never after workflow phases or milestones (`v6_m*`, `v6_w*`, `m4_lane*`). Keep `crates/wasm/Cargo.toml` `[[test]]` entries synchronized whenever new WASM integration tests are added. After `--build-wasm` (`crates/wasm/scripts/assemble_pkg.mjs` + `crates/wasm/scripts/assemble/*.mjs` [13 modules], `crates/wasm/tests/node_esm_smoke.mjs` + `crates/wasm/tests/esm_smoke/*.mjs` [11 modules]) and `npm --prefix examples/web run build`, run `node crates/wasm/tests/playwright_smoke.mjs` to verify Chromium `memory.grow` detach recovery, `N=5,000` `runProgressive` `<= 10 ms`/frame budget, and all 13 `examples/web` routes.
7. **Single-thread SciPy / DKE micro-benchmarks**: Run comparative benchmarks from `egraph-rs/.venv` under explicit single-thread guards (`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1`) with DKE kept strictly read-only (stub `sys.modules["utils"]` if needed to avoid `matplotlib` imports). Report pure-Python/SciPy-sparse graph preprocessing (`1+2hop`, `Track-A`) separately from C++ `_sparsetools`-backed SciPy SpMM kernels (`DoG-Var`).
8. **Local Release Packaging Clean-Env Smoke Recipes**:
   - **Python wheel & `sdist`**: Build into a scratch output dir under `<appDataDir>/scratch/teamwork_tmp/<id>` (`maturin build --manifest-path crates/python/Cargo.toml --release -o "$TMP/dist"` for fast local checks or `--profile dist-release` to match `.github/workflows/release.yml`, and `maturin sdist --manifest-path crates/python/Cargo.toml --out "$TMP/dist"`), then install each into a fresh `python3 -m venv` (without `egraph-rs` editable checkout on `sys.path`) and verify `import importlib.metadata as md, egraph as eg; assert eg.__version__ == md.version("egraph") == "<pep440>"` (matching `CARGO_PKG_VERSION` in PEP 440 form, e.g. `6.0.0a8`, and intentionally omitted from `egraph.__all__`) + `CsrGraph` / `TsNetSolver` / `SgdSolver.sparse_barrier_dog` / `evaluate_metrics` smoke execution. See `egraph-rs-release` for live PyPI/npm post-tag verification and canonical `evaluate_metrics` keys.
   - **npm ESM tarball**: Run `(cd crates/wasm && npm pack --dry-run && npm pack --pack-destination "$TMP")` after `--build-wasm`, verify `package/package.json` retains `"repository": {"type": "git", "url": "git+https://github.com/likr/egraph-rs.git", "directory": "crates/wasm"}` for `--provenance`, and smoke-import the unpacked tarball in Node.js ESM (`npm install --prefix "$TMP/consumer" "$TMP"/egraph-*.tgz`).
9. **Synthetic NP2 Test Fixtures for `SpatialIntruderRefiner`**: Because `SpatialRefinerConfig` defaults (`w_fn=0.0`) preserve initial 1-hop edge lengths, avoid asserting NP2 improvements on tiny lattices with an artificially stretched single-node edge whose outcome depends on RNG permutation order (e.g., after Lemire RNG refactoring). Use realistic folded fixtures (such as a `2x8` folded grid strip) where 1-hop edges remain near unit scale while distant `>2`-hop layers overlap, verifying across both `float64` and `float32`.
10. Always pass `--no-pager` on `git diff`, `git log`, and `git show` commands.
11. In swarm sessions, post a brief `@coordinator [interim]` status update on the board before starting any command expected to take `>60s` to prevent false monitor `[stall]` alerts.
12. **Diff-Keyed Verification Deduplication & Cold-Rebuild Prohibition**:
    - Check `df -h .` (`>= 25 GiB` free recommended) before launching `--all` or parallel worktree builds (`scripts/verify.sh` emits a warning if below `25 GiB`).
    - Never re-run `./scripts/verify.sh --all --build-wasm --docs` redundantly across Worker, Reviewer, Auditor, or post-merge root validation when the code diff is already verified. Verify either unchanged `HEAD` (`git rev-parse HEAD`) or byte-identical rebase (`diff -u <(git diff <old_base>..<verified_sha>) <(git diff <new_base>..HEAD)` producing empty diff), inspect the existing `--json-summary`, and run only warm incremental smoke checks (`.venv/bin/python -m pytest -q <targeted_test>`, `node crates/wasm/tests/node_esm_smoke.mjs`, `./target/release/egraph --help`) or complementary adversarial probes.
    - **Prohibit cold full-workspace `--release` rebuilds**: Never set an empty `CARGO_TARGET_DIR` (e.g., `/tmp/...`) to recompile all 27 crates in `--release` during an Auditor or Challenger check; build isolated probes either as minimal single-crate dependents or against warm workspace artifacts with `sccache`.
    - For **version-bump-only commits** (zero Rust/Python/WASM logic diffs; only manifest/lockfile/docs bumps per `egraph-rs-release`), run `EGRAPH_PARALLEL_WORKERS=1 ./scripts/verify.sh --invariants --docs` plus clean-env wheel/`sdist`/`npm pack` smoke checks instead of repeating full unit suites already green on the parent commit.
13. **TypeScript Declaration Check after `--build-wasm`**:
    - Whenever `crates/wasm/scripts/assemble_pkg.mjs`, `crates/wasm/scripts/assemble/*.mjs` (11 modules), or WASM bindings change, always run `npx tsc --noEmit` against the assembled `crates/wasm/pkg/index.d.ts` before handoff to catch stripped or overwritten type exports early.
14. **Brute-Force Oracle & Adversarial Edge-Case Testing Before Review**:
    - For any change to `egraph-spatial*`, `egraph-linalg*`, `egraph-layout*`, or `egraph-metrics*` kernels, authors MUST cover before requesting review:
      - Randomized + degenerate brute-force $O(M^2)$ / $O(N^2)$ oracle tests for geometric kernels (collinear overlaps, shared endpoints, floating-point tie-breaks, periodic boundaries).
      - Graph & layout boundary cases: empty (`N=0`), singleton (`N=1`), edgeless, **directed graphs with reciprocal edges `(u, v)` + `(v, u)`** (catching inclusion-exclusion `saturating_sub` bugs), mixed connected + isolated degree-0 vertices, and **1D / axis-aligned / 2-cluster collinear layouts** (ensuring isotropic scale extraction uses `&&` not `||` on axis spans).
      - Iterative linear solver precision sensitivity: when solver outputs feed nonlinear transforms such as `-log(...)` (e.g., `RHGH`), validate end-to-end distance accuracy against exact dense solves (using tight tolerances like `rel_tol=1e-12`, not `1e-8`).
      - Cross-target Native vs. WASM parity fixtures: use asymmetric graphs (or rotation-invariant comparisons) for spectral/PivotMDS pipelines so multiplicity-2 eigenvalues do not trigger false 90-degree eigenbasis flips from `1e-16` FMA differences.
15. **Structured Sync Verification Over Static Shell Parsing**:
    - Verify synchronization across `Cargo.toml`, `scripts/verify.sh`, `scripts/verify_helpers.py`, `scripts/check_invariants.sh`, and `.github/workflows/{ci,release}.yml` via structured metadata parsing (`cargo metadata`, TOML/YAML/JSON, `verify_helpers.py`) and live `--json-summary` outputs rather than building custom static Bash interpreters inside audit scripts.
    - When adding or refactoring crate/test matrices in `scripts/verify.sh`, prefer exposing machine-readable lists from `scripts/verify_helpers.py` so cross-file sync checks stay trivial and deterministic, and never spend `> 2` iterations hardening temporary scratch verification scripts.
16. **Colab Tutorial Notebook Verification (`notebooks/01..09_*.ipynb`)**:
    - When verifying updated notebooks on Google Colab *before* a pre-release wheel is published on PyPI, build a Linux `x86_64` `abi3` wheel via Docker (`ghcr.io/pyo3/maturin:latest` with `--target x86_64-unknown-linux-gnu --compatibility manylinux_2_28 --release`) and test on Colab (`colab-cli`), keeping Cell 1's PyPI pin aligned with the currently released or explicitly targeted package version.
    - In Matplotlib plots using `matplotlib-fontja` for Japanese labels on Colab, avoid `fontweight="bold"` on CJK text (which triggers `findfont` warnings when the Japanese fallback font lacks a bold face).
    - Always stop Colab runtimes and assert `colab sessions` shows `No active sessions found on server.` before handoff.
